# 선릉 바이브코딩 해커톤 — 행사 안내 페이지

2026년 10월 31일(토) 14:00–20:00, 선릉에서 여는 **개인전 6시간 해커톤**의 안내 한 장이다.
정적 HTML 한 파일이고 빌드가 없다.

- 신청·운영: [HACK:ON](https://hackon.mandeun.com) ([소스](https://github.com/mandeun/hackon))
- 주최: mandeun

## 왜 이렇게 설계했나

참가자 불만 조사에서 나온 세 가지를 정면으로 겨냥했다.

| 흔한 불만 | 이 대회의 답 |
|---|---|
| 밤샘 포맷이 돌볼 가족이 있는 사람·체력 문제가 있는 사람을 걸러낸다 | **토요일 오후 6시간, 20시 종료** |
| 팀 매칭에 시간이 녹고, 한 명이 안 오면 팀이 무너진다 | **전원 개인전** |
| 우승자만 발표하고 나머지 결과물은 그날로 사라진다 | **갤러리 워크 + 전원 점수 분해·심사평 공개** |

## 고치고 배포하기

`index.html` 한 파일만 고치면 된다. main 에 push 하면 Vercel 이 자동 배포한다.

```bash
python3 -m http.server 8000   # 로컬 미리보기 → http://localhost:8000
```
